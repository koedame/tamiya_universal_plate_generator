# Security Policy

## Reporting a vulnerability

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/koedame/tamiya_universal_plate_generator/security/advisories/new).
Do not open a public issue for them.

We will reply within 7 days to confirm that we received your report, and keep you updated until it is fixed.

## Supported versions

Only the `main` branch receives security fixes.

## What counts as a vulnerability

- Code execution or script injection through the generator script or its parameters
- A vulnerable dependency that is reachable from the generator
